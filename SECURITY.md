# Security

ModMyFeed is a browser extension that reads Reddit content already rendered in the user's tab, so security and privacy reports are taken seriously.

Before reporting, see `TRUST.md`, `VERIFY.md`, and `PRIVACY.md` for the intended architecture and current data-handling behavior.

## Reporting a concern

For ordinary security/privacy bugs, open a GitHub issue with enough detail to reproduce the problem.

For a potentially sensitive vulnerability, **do not publish exploit details in a public issue**. Open a minimal issue titled `Security: request private contact` without sensitive technical details so a private channel can be arranged.

Useful reports include an unexpected network request, access to a website other than Reddit, storage of data not described in the privacy statement, a way for imported preset data to execute code, unsafe DOM injection behavior, or a dependency/permission added without a clear need.
